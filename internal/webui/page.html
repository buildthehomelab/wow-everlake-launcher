Use an existing installation

Close the game and Battle.net first. Import creates a verified copy and keeps your original for recovery. Rerun the same import to resume an interrupted copy.

Low disk space: updates the existing folder without a second client or duplicate asset cache. Keeps addons and settings; replaces the old build. Only single-product installations are supported. Temporary space for changed files is still required.

Use an older install to reduce downloads. Matching files are verified and copied; only missing or damaged files download. Keep Battle.net and the game closed. Use a separate destination with space for the new client. Repeat with the same folders to resume.

After importing Forever, use Change to select the new folder.
