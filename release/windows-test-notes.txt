Opt-in Windows test build that installs WoW Forever 1.60.1.70938, Blizzard's live build since 13 November 2026 (the regular launcher installs 1.60.1.70790). It is a pre-release: launchers are never updated to it, and it does not replace itself with the regular release. Built from pull request #33.

What is not known yet: the game has never been run on 70938 with this launcher. The update itself and the login-name change were checked against the real 70938 files; the server key is only handled in the running game, at login. This build is for finding that out.

Before testing
- The realm must already accept 70938 clients. If it does not, you get no realm list whatever the launcher does.
- Pick how to test:
  - Safest: open Use an existing installation, choose Forever, set Existing client folder to your current game folder (the one with .build.info and Data) and New destination folder to an empty folder, then Install using existing files. Your current install is only read and stays on 70790; the new folder reuses its matching files and downloads the rest. It needs disk space for a second client.
  - In place: open the launcher on your current folder. The status line says "You have build 1.60.1.70790" and Update moves it to 70938, downloading only changed files. To go back afterwards, run the regular launcher's command-line program: everlake-launcher-cli-windows-amd64.exe install --dir <your folder>.
- A folder with the Classic overlay is not updated in place: no overlay exists for 70938 yet, and the launcher says so. Use the safest way above for it.

Test
1. Download everlake-launcher-windows-amd64.exe and start it.
2. Install or update as chosen above, then Verify files.
3. Play, sign in, pick a character and stay in the world for at least a minute.

What to report (Log, then Save diagnostics, or copy the lines)
- "login name: any name allowed (1 of 1 table entries)" should appear soon after the game starts.
- "server key: written (region group 8)" should appear when you log in. If the log stays at "server key: waiting for the game to open its key store" after you pressed Log in, this build does not find the key store on 70938, and that line is the result we need.
- Whether you reached the character list, entered the world, and whether the game closed by itself.

The executables are unsigned. SHA256SUMS.txt is included for integrity checks.
