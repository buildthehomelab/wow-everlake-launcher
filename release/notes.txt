Regular launcher update for Windows and macOS, delivered through the launcher's own updater.

The Everlake addon now lists every primary profession on the game's own Professions page. The page had room for only the professions in the game's two slots; its top part is now a scrolling list of every primary profession you know, each in the game's style: its profession art, spell buttons with rank, the game's animated profession bar, and the red X to unlearn it (with a confirmation). Cooking, Fishing and First Aid below stay as the game shows them. In combat the page stays as the game made it. The side tabs on the profession window now sit exactly like the game's own and only one shows as selected. (alpha.10's separate Professions window never opened on this client; it is gone.)

Validation: Windows, Linux and macOS test suites, runs of the addon against stand-in game frames, and the page tried in game with a test copy of the addon.

Windows executables are unsigned; the Mac app is ad-hoc signed and not notarized. Both platforms and SHA256SUMS.txt are included.
