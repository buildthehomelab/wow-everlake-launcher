Regular launcher update for Windows and macOS, delivered through the launcher's own updater.

Fixes the game quitting about 10 seconds after Play, with no error window, after the update to build 1.60.1.70959. The game's log (Logs\Tact.log) says "Missing segment header for archive '0', repair needed". Each game data archive starts with 16 small records that the game checks when it starts. Earlier launchers didn't write them, and the update deleted the ones the game had added. Build 70959 refuses to start without them.

After this update the launcher shows "Needs repair" for most installs. Press Repair (or Install): it writes the missing records, moves the few files they replace, and removes the game's repair marker. Almost nothing is downloaded. Then press Play.

New archives get the records from the start, and later updates keep them.

Validation: Windows, Linux and macOS test suites. On a Windows PC with this error, a test build of this fix repaired the install and the game ran again. On macOS, the 70959 game failed with the same error after its records were removed, and opened its storage after the repair.

Windows executables are unsigned; the Mac app is ad-hoc signed and not notarized. Both platforms and SHA256SUMS.txt are included.
