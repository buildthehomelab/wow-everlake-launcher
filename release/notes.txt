Regular launcher update for Windows and macOS, delivered through the launcher's own updater.

Moves the game to WoW Forever 1.60.1.71091, Blizzard's update of 24 November 2026 (the realms are on 71091 now). Install and Verify update a client on 70959 or an earlier build in place; only the files that changed are downloaded. Nothing is forced: a client you don't update keeps working while the realms still let its build in.

Validation: Windows, Linux and macOS test suites. On 71091's real Windows Wow.exe, the launcher still finds the table it writes the realm's key into (one entry, in .data). A 71091 client joined the test realm. Playing on 71091 with this launcher build has not been seen yet.

Windows executables are unsigned; the Mac app is ad-hoc signed and not notarized. Both platforms and SHA256SUMS.txt are included.
