Regular launcher update for Windows and macOS, delivered through the launcher's own updater.

The launcher now installs WoW Forever 1.60.1.70938, Blizzard's live build since 13 November 2026. Until now it installed 1.60.1.70790.

Nothing changes until you choose it. Play keeps starting the build you already have. With 1.60.1.70790 installed, the status line says so, and Update moves the game to 1.60.1.70938, downloading only the files that changed. Verify files checks your client against the build it has.

Before you update the game: this launcher cannot put 1.60.1.70790 back. To keep it, open Use an existing installation, choose Forever, give your current game folder and an empty new folder, and choose Install using existing files. The new folder gets 1.60.1.70938, reusing every matching file, and your current folder stays as it is. That needs disk space for a second client.

A folder with the Classic–Wrath prototype overlay stays on 1.60.1.70790: there is no overlay for 1.60.1.70938 yet, and the launcher says so and leaves the folder alone. Play and Play Classic–Wrath prototype keep working there.

Validation: Windows, Linux and macOS test suites. The new build read from Blizzard's CDN. A real update of the Windows game program files from 1.60.1.70790 to 1.60.1.70938: only changed files fetched, full verification intact, and the same game executable as a fresh install. The login-name change the launcher makes was checked against the real 1.60.1.70938 game executable.

Not validated yet: playing on 1.60.1.70938 with this launcher. The realm's key is put into the running game at login, which cannot be checked without the game. If the launcher's log stays at "server key: waiting for the game to open its key store" after you log in, close the game, use Log, Save diagnostics, and report it.

Windows executables are unsigned; the Mac app is ad-hoc signed and not notarized. Both platforms and SHA256SUMS.txt are included. The version goes to 0.1.2-alpha.1 so the regular releases and the Windows test build v0.1.1-alpha.2-windows-test.1 all recognise it as newer.
