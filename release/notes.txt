Regular launcher update for Windows and macOS, delivered through the launcher's own updater.

Fresh data after a realm update: Play now empties the game's Cache folder after you sign in and before the game starts. The game keeps creature, quest and item data and hotfixes there, and could keep showing old data after the realm changed. Only the folder's contents are removed, files in use are left alone, and a problem never stops the launch. To keep the cache, set "clear_cache": false in launcher.json.

macOS:
- The launcher clones the game app instead of copying it in full before each launch, so starting the game is quicker and takes almost no extra disk space on APFS (the standard Mac disk format). Other disks get a full copy as before.
- The realm key is written into the game with a safe memory write: if the game moves its key store at the wrong moment, the launcher tries again instead of crashing the game.

Validation: Windows, Linux and macOS test suites, including a new macOS test that puts the key helper into a stand-in program holding a key store and checks it writes the realm key, and leaves a store it does not recognise alone. Not yet checked with the real game client on macOS.

Windows executables are unsigned; the Mac app is ad-hoc signed and not notarized. Both platforms and SHA256SUMS.txt are included.
