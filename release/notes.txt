Regular launcher update for Windows and macOS, delivered through the launcher's own updater.

Play now brings the Everlake addon up to date before the game starts. Until now the launcher wrote the addon only on Install, so after a launcher update the game kept the previous addon until the next Install (alpha.10's Professions window did not show for players who only pressed Play). When the addon is already current, Play writes nothing; an older copy is kept in .everlake\addon-backups. A folder named Everlake that the launcher did not make is left alone, with a note in the log.

Validation: Windows, Linux and macOS test suites, including a test that an older addon is refreshed and an unmanaged folder left alone. Not yet tried on a player's PC.

Windows executables are unsigned; the Mac app is ad-hoc signed and not notarized. Both platforms and SHA256SUMS.txt are included.
