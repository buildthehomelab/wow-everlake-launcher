Regular launcher update for Windows and macOS, delivered through the launcher's own updater.

Play no longer deletes the game's saved hotfixes. Since v0.1.2-alpha.2, Play emptied the whole Cache folder before joining a realm, including Cache\ADB, where the game keeps the realm's hotfixes. Now it empties only Cache\WDB, the creature, quest and item data that goes stale when the realm changes. Without its saved hotfixes the game downloads all of them again while entering the world. Some players' games have crashed on the loading screen since the last update (ERROR #132 ACCESS_VIOLATION). We don't know yet whether the missing hotfix cache causes that crash.

To keep the whole Cache folder, set "clear_cache": false in launcher.json, as before.

Validation: Windows, Linux and macOS test suites, including new tests that Play empties WDB and leaves ADB and everything else alone. Not yet checked with the game.

Windows executables are unsigned; the Mac app is ad-hoc signed and not notarized. Both platforms and SHA256SUMS.txt are included.
