Regular launcher update for Windows and macOS, delivered through the launcher's own updater.

The launcher now installs and updates the game to Blizzard's WoW Forever build 1.60.1.70959, the Battle.net update of 17 November. A game on 70938 updates to 70959 the next time you press Play or Install. Only 62 files changed between the two builds (game tables, interface files and the game programs), so the update is small. No map, model or texture files changed.

If you play with the Classic overlay, the launcher keeps your game on 70938 until the overlay for 70959 is published.

Validation: Windows, Linux and macOS test suites. The login-name patch was checked against the real 70959 Windows Wow.exe. Not yet checked by joining the realm with a 70959 game.

Windows executables are unsigned; the Mac app is ad-hoc signed and not notarized. Both platforms and SHA256SUMS.txt are included.
